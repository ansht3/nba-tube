# NBATube

A calm place to watch official NBA video: game highlights, player highlights,
and pregame and postgame media sessions, taken only from the league's and the
teams' own YouTube channels. No recommendation algorithm, no comments, no
account.

NBATube is an independent open-source project. It is not affiliated with the
NBA, its teams, any broadcaster, YouTube or Google. Videos play in YouTube's
own embedded player and are never downloaded or rehosted.

Setup instructions land here as the app takes shape.
